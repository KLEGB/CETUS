# CETUS 9.1：多波段长波辐射接口与物理设计

## 版本与范围

在 1.9 完整照明版本上实现。默认未启用 `longwave.enabled` 时继续使用原灰体长波；太阳短波的可见光/NIR 分离和照明记账保持原有实现。9.1 更新 Python 与 Go 的外表面长波热平衡，保留原室内灰体辐射参数，不将外涂层的选择性发射率自动施加到内表面。

独立 `ENERGY.simulate_surface` 可在没有几何的情况下使用分波段天空/地面边界。`simulate_coupled` 的分波段建筑—地面交换使用已有 RAD 视因数，需要 RAD 网络；不会重建一套室内或外部几何。

## 输入示例

```python
options = {
  "longwave": {
    "enabled": True,
    "sky_mode": "prescribed",
    "reflection_mode": "one_bounce",
    "reference_temperature_k": 300.0,
    "bands": [
      {"name":"below_8", "lower_um":0, "upper_um":8,
       "atmospheric_transmittance":0.02},
      {"name":"window_8_13", "lower_um":8, "upper_um":13,
       "atmospheric_transmittance":0.75},
      {"name":"above_13", "lower_um":13, "upper_um":None,
       "atmospheric_transmittance":0.02}
    ],
    "materials": {
      "roof": {
        "emissivity": {"below_8":0.10,"window_8_13":0.95,"above_13":0.10},
        "reflectance": {"below_8":0.90,"window_8_13":0.05,"above_13":0.90}
      },
      "ground": {
        "emissivity": {"below_8":0.10,"window_8_13":0.95,"above_13":0.10}
      }
    }
  }
}
```

- 单位为 μm，最后一个上界用 Python `None` / JSON `null` 表示无穷。波段必须完整、有序覆盖 [0,∞)，不允许重叠或留空。首版采用波段内常数系数。
- `materials` 接受 `wall, roof, window, skylight, ground, land, water`。`ground` 为暴露硬质地面和道路的合并组；没有给定的材料沿用对应灰体发射率。楼板仍是接触边界，不参加外部长波。
- 可选 `building_materials={"0":{"roof":{...}},"1":{...}}` 按零起算建筑索引覆盖指定建筑的外表面材料；仅影响耦合网络中的对应建筑。独立单栋入口应直接使用 `materials`。
- 材料 `emissivity`/`reflectance` 均用波段名称映射数值。
- 未设置某波段反射率时，取该材料其他显式设置波段的反射率**算术平均值**；所有波段反射率都未设置时，由不透明近似取 `1-emissivity`。不会混入太阳短波反射率。
- 不透明材料默认要求逐波段 ε+ρ=1，且吸收率 α=ε（Kirchhoff）。回填平均值导致不闭合时会报错，不会静默归一化参数。
- 高级外部薄膜可设 `opaque=False`，此时要求 ε+ρ≤1，余量作为长波透射记入 `lw_material_transmission_out_w`。该能量离开当前外部辐射网络，**不会自动给建筑内部加热**；因此它不能替代完整半透明围护结构的光热模型。一般墙面/屋面请保持默认不透明模式。

## Planck 加权与“发射率积分小于 1”

波段黑体出射度为

\[
B_b(T)=\int_{\lambda_{b,lo}}^{\lambda_{b,hi}}\pi I_{BB}(\lambda,T)\,d\lambda,
\qquad \sum_b B_b(T)=\sigma T^4.
\]

表面出射度为 \(E_s(T)=\sum_b\epsilon_{s,b}B_b(T)\)。校验的总发射率为

\[
\epsilon_{eff}(T)=\frac{\sum_b\epsilon_{s,b}B_b(T)}{\sigma T^4}<1.
\]

每个 ε 在 [0,1] 内，以参考温度校验加权积分严格小于 1；不对 ε 的原始数值直接求和。比如 [0.10,0.95,0.10] 虽然原始和为 1.15，300 K 加权总发射率仅约 0.374，满足条件。强制原始和小于 1 会使结果依赖人为分了多少个波段。

Python 用无量纲 Planck 积分的级数计算预表；Go 独立建立相同波段出射度表。173.15–453.15 K 采用 0.05 K 线性插值，区间外回到积分级数。Go 非线性求解使用分段导数；外部辐射能量与输出审计均使用相同表。表面外部发射直接依赖迭代温度，不是事后附加一个材料修正因子。

## 大气与天空

用户给的是天空方向的**有效半球透过率**。它与沿天顶测得的透过率不同；没有进行逐天空角度的 MODTRAN/分子谱线传输，也不对 200 m 内的表面间空气路径做逐谱吸收。

在 `prescribed` 模式下，逐时背景温度取气象背景温度 Tb：

\[
L_{sky,b}=(1-\tau_{atm,b})B_b(T_b).
\]

外太空约 3 K 的返回长波在这些温度下忽略。用户输入的有效透过率决定谱天空，**代替 EPW 总长波边界**，不会再叠加一份原 EPW 天空辐射。此模式适合明确的大气情景对照；固定 0.75 窗口透过率不是从本 EPW 实测反演得到的。

`epw_matched` 是可选的天气兼容模式：对整个透过率谱做同一光学厚度缩放 \(\tau'_b=\tau_b^s\)，令 \(\sum_b(1-\tau_b^s)B_b(T_b)=L_{EPW}\)。这是用总长波约束谱形的近似，不能替代水汽/云量的光谱传输。若总长波高于背景黑体、或包含 0/1 的谱使目标不可达，则明确报错，要求选择合适的谱或情景模式。

向天空出射中，\(\tau_b L_{up,b}\) 记为穿过大气逃逸到空间，余量记为大气吸收。大气吸收不直接等同于城市冠层气温升高，本版没有垂直大气辐射—动力学模型，也不将它再次直接加入 UHI 空气热源。

## 一次反射和能量审计

复用几何视因数矩阵 F，外部天空及远场环境入射为 L。默认 `one_bounce`：

\[
H^{(0)}=FE+L,\quad J^{(1)}=\rho H^{(0)},\quad H=H^{(0)}+FJ^{(1)}.
\]

对受照表面按自身波段参数计算吸收 \(\sum_b\epsilon_{s,b}H_{s,b}\)；没有“继承光源材料反射率”的情况。表面的净向外长波为 \(E_s-\alpha_s H_s\)。地面三个热节点分别使用自身温度、发射率及吸收率；它们仍共享已有合并地面几何视因数。

一次反射后接收面仍会反射的 \(\rho FJ^{(1)}\) 没有继续追踪，单独列为 `lw_second_reflection_unresolved_w`。它既不是热吸收，也不宣称已经逃到太空。此项可能导致一次反射相对于完整长波反射的偏差，尤其是高反射涂层和低天空可视度区域。**守恒账本闭合并不意味着该截断误差很小。**

完整账本逐波段检查：

\[
\text{表面发射}+\text{外部入射}=
\text{表面吸收}+\text{天空/远场出射}+
\text{未追踪的二次反射}+\text{材料透射}.
\]

保留 `radiosity` 参考模式，求解 \(J=E+\rho(FJ+L)\)，用于核对一次反射截断的影响；默认不启用。该模式的未追踪反射为 0。不要将一次反射与完整反射的结果混合在同一个材料差值中。

## Energy 与二进制接口

`longwave_bands` 作为 Go 表面的可选静态参数，包含 `lower_um, upper_um, emissivity`。JSON 配置直接支持；CES3 v1 原字段布局保持不变，新增显式 opcode **10 `register_spectral`**，在 opcode 1 注册普通模型后、begin_step 前注册波段。旧引擎会拒绝该 opcode，不能把旧 `.exe` 与新 Python 混用。文件编码 CLI 会为含波段的模型自动插入该注册帧。

为复用现有高频输入字段，`network_ir_w_m2` 在谱模式下是“等效入射”：其与原灰体 `emissivity` 的乘积等于已按谱吸收率加权的入射功率密度；不再当作可独立解释的物理总辐照度。Go 在外表面使用

\[
Q_{LW,out}=A\,[\sum_b\epsilon_b B_b(T_s)-\epsilon_{carrier}I_{equiv}],
\]

内部长波仍用原灰体参数。真实逐波段辐射量见 `longwave_bands_hourly.csv`。使用此低层协议时必须提供谱等效边界；直接给一个普通总长波数值将没有正确的谱含义。

分波段配置进入重启签名；更换材料/大气参数后旧热状态重启会被拒绝。短波几何缓存可以复用，因为长波涂层本身没有改变短波参数。

## 对照解释

本轮主要比较两种 300 K 总发射能力匹配的表面：灰体 ε≈0.37383，以及 ε=[0.10,0.95,0.10] 的窗口选择性材料。另有宽波段 ε=0.9 参考。匹配总发射能力可以区分谱分配效应；它不代表所有普通建材都具有约 0.374 的发射率。

高窗口发射率能够促进通过窗口的散热，但是否降低表面温度/气温还取决于太阳吸收、表面温度、大气透过、天空可视度、风速及空调排热。对 ε=0.9 的宽波段材料，选择性材料不保证在所有高温工况下都更优。

参考：Raman et al. (2014), Nature 515, 540–544, https://doi.org/10.1038/nature13883；Jeon and Shin (2020), Scientific Reports, https://doi.org/10.1038/s41598-020-70105-y 。这些研究支持谱选择性辐射冷却的物理结构，不是当前 CETUS 参数的实测标定来源。
