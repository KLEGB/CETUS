# CETUS 1.9：等太阳透射率玻璃的能耗对照

## 对照设计

沿用 756 栋建筑、总 GFA 2,415,770.8 m² 的 SHP/EPW 算例，HOY 5016–5087（零起算），共 72 小时；随机种子 42，各组独立周期预热。复用同一辐射网络、同一窗面积、热阻、太阳反射率、长波发射率和使用日程，只改变玻璃光谱透射率及日光控制开关。

| 参数 | 普通玻璃 | 选择性玻璃 |
|---|---:|---:|
| 可见光透射率 | 0.4263157895 | 0.7000000000 |
| 近红外透射率 | 0.4263157895 | 0.2000000000 |
| 其余短波透射率 | 0 | 0 |
| 加权总太阳透射率 | 0.405 | 0.405 |

光谱能量权重分别为可见光 0.43、近红外 0.52、其余短波 0.05。普通玻璃的“相同透过率”仅指可见光和近红外，两种玻璃的其余短波透射均保持为 0。

$$0.43\times0.4263157895+0.52\times0.4263157895=0.43\times0.7+0.52\times0.2=0.405.$$

这里匹配的是太阳直接透射率；在本模型中，另保持反射率、吸收率及玻璃向内传热条件相同。实际产品仅有相同的太阳透射率，不能单独证明其 SHGC、U 值或吸收得热相同。

## 差异来源

相同入射辐射下，选择性玻璃的估计日光照度为普通玻璃的 1.641975 倍（提高 64.20%）。普通玻璃照度在 182.71–300 lx 之间的控制区，有机会因换玻璃而达到 300 lx 并关灯；原来两种玻璃均高于或低于阈值的时段，不产生开关差异。

逐区逐时匹配 320,544 个记录，其中 26,987 个记录从需要开灯变为无需开灯，合计对应 15,782,570.78 m²·h。该面积时数包含照明原始日程为零的情况，不能直接乘安装功率得到节电量；电耗表已应用原始逐时日程。照度倍率关系的最大绝对误差为 1.82e-12 lx。

两种玻璃的太阳总透射没有减少：可见光透入能量增加，恰好由近红外透入能量减少抵消。在当前热模型中，可见光也进入太阳热平衡，因此本实验的空调差异来自照明内热源减少及其与 UHI 的耦合反馈，而不是把近红外减少量全部当作太阳热节约。

## 验证与解释范围

新增匹配太阳透射率、照度倍率与阈值开关专项测试；36 项 Python 测试通过。能耗差值通过独立耦合运行得到；选择性玻璃两组复用本轮 1.9 已完成的同输入输出，普通玻璃两组新运行。关闭日光控制时逐时热工结果应一致，详细数值差异见 comparison.json。

本实验不是 ASHRAE 140 的标准玻璃采光算例，而是 CETUS 的受控敏感性实验。沿用的 SHP 重心约 38.35°N、114.68°E，而 EPW 为龙岩；结果用于同输入的机制比较。照度利用系数与光谱权重仍为先验，此 72 小时高温窗口不能推广为全年节能率。冬季照明得热减少可能增加供热需求，全年净影响需另做全年运行。

两者合计只含 HVAC 与照明。实际节能还依赖可用的照明开关/调光行为，本实验设受控份额 100%；未配置日光控制时，本模型中的两种玻璃没有该采光节能收益。

## 复现

完整源码位于包内 CETUS_1.9；输入 SHP/EPW 沿用既有算例。
```bash
python CETUS_1.9/test/scripts/run_19_glass_comparison.py --shp case/53695_3092_LCZ1_2B.shp --epw case/CHN_FJ_Longyan.589270_TMYx.epw --output outputs_reproduce
```

energy_comparison.csv 为四组汇总；hourly_comparison.csv 为开启控制时的配对逐时功率密度和温度；每组目录保留 summary.json、hourly.csv 与 audit.json，开启控制还保留 daylighting_hourly.csv。图提供 PNG、SVG 和矢量 PDF。
