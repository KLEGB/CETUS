# V8.3 变更

基线：V8.2，提交 `1c748918862fb418261dc7c69aab1718c751c04a`。

- 新增 CES3 v1 二进制协议，Python 客户端及独立 JSON/二进制文件转换 CLI。
- 新增不可变时间步缓存，显式 dynamic_fields、response_level、return_state、aggregation。
- 耦合默认使用二进制；保留 JSON 模式及旧 SurfaceEngine。
- 缓存 Go 拓扑，复用每建筑工作矩阵；轻量响应跳过详细表面诊断量构造。
- 每个根求解内复用固定建筑长波发射项；点级长波结果每物理小时最终刷新。
- 表面可见性查询按约 40,000 条合批，空链接场景也可建立空稀疏矩阵。
- 自动编译签名涵盖全部生产 Go 源码，适配新增 binary.go。
- 新增接口/状态/异构模型/错误恢复/二进制文件测试及并行工作区 race 测试。

旧输出文件、状态节点定义、热工模型协议 cetus-surface-7、RAD 缓存协议 cetus-rad-network-8 保持兼容。V8.3 的单会话只保存一套注册模型集合；多模型组可使用多个引擎实例。

没有变更物理方程、天空模型、短波反射阶数、材料先验、采样点、交换半径或收敛阈值。
