# CETUS V8.1 module

Energy V7 + RAD V8.1 + UHI, including SITE and WEA.
Python requirements: `pip install -r requirements.txt`.
Linux/Windows Energy and radiation transport runtimes and required model parameter files are included.

Windows/skylights absorb exterior longwave radiation with zero longwave transmission and zero thermal storage. Indoor solar transmission uses primary plus reflected shortwave only.

No case inputs, simulation outputs, radiation caches, validation reports or Git history are included.
